# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

DungeonCrawler is a Godot **4.7** project (`project.godot`, `config_version=5`), currently a fresh template with no scenes or scripts yet.

Engine settings worth knowing:
- Renderer: Forward+; Windows rendering driver is **D3D12**.
- 3D physics engine: **Jolt Physics** (not Godot Physics). Keep this in mind for physics behavior and API differences.
- Window stretch: `canvas_items` mode, `expand` aspect.
- No main scene is configured yet (`application/run/main_scene` is unset). Running the project will prompt for one until it is set.

## Commands

Requires the Godot 4.7 editor binary on PATH (referred to here as `godot`).

- Open in editor: `godot --editor --path .`
- Run the project: `godot --path .` (or `godot --path . res://path/to/scene.tscn` for a specific scene)
- Headless import / check for script errors: `godot --headless --path . --import`
- Run a single script headlessly: `godot --headless --path . --script res://path/to/script.gd`

No test framework, linter, or export presets are set up yet.

## Conventions

- `project.godot` and `*.import` files are generated by the editor. Prefer changing settings through the editor; if hand-editing, keep Godot's formatting.
- `.godot/` is an editor cache and is gitignored. Never commit or edit it.
- Files are UTF-8 with LF line endings (`.editorconfig`, `.gitattributes`).
- Resource paths in scenes and scripts use `res://`. Moving or renaming files outside the editor breaks references (including `uid://` references in `.tscn` and `.import` files), so update those references too.
